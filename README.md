HR ANALYTICS DASHBOARD USING EXCEL

PURPOSE 
This project is created to analyse attrition rate of employees across departments,job role, education field,gender,age groups and overtime.The main aim is to understand the root cause that influence the attrition. 

TECH STACK
Microsoft excel
Pivot tables
Pivot charts 
Slicers
Data cleaning and transformation 
Dashboard design.

DATA SOURCE
IBM HR analytics employees attrition dataset (kaggle).

FEATURES/HIGHLIGHTS 
Analyse department wise attrition 
Analyse gender based attrition 
Analyse attrition by education field 
Analyse attrition by job role
Analyse attrition due to overtime 
Analyse attrition on the basis of age group 

KEY FINDINGS 
Research and development department has highest attrition 
Male employees have more attrition rate than female employees
The 20-30 age group employees have highest attrition 
In education field life science has highest attrition 
Employees working as laboratory technician has highest attrition
